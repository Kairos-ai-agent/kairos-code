# 剧本视觉资产提取 · Script-to-Visual Asset Extraction

从完整剧本中提取所有视觉资产（角色、场景、道具），生成可直接用于 AI 图像生成的提示词文档。是 storyboarding 之前的必做准备工作。

## 工作流程

```
完整剧本 → 通读分析 → 角色提取 → 场景提取 → 道具提取 → 提示词生成 → 结构化文档
```

## 第一步：通读分析

### 阅读策略
- **通读全文**：先完整阅读剧本，建立角色关系和故事线的整体认知
- **标记关键信息**：每出现一个新角色/场景/关键道具就记录下来
- **建立关联**：记录每个角色出现的集数、每个场景承载的关键情节
- **识别风格**：从剧本的视觉描述中提炼整体风格关键词（写实/赛博/古风/二次元等）

### 提取优先级

| 资产类型 | 提取重点 | 重要性标记 |
|---------|---------|-----------|
| 主角/主要配角 | 外观、年龄、服装、性格、道具关联 | ⭐主线 |
| 反派/导师 | 外观、特殊改造、与主角关系 | ⭐关键 |
| 群像/量产角色 | 统一特征、差异化标记 | 重要 |
| 核心场景（反复出现） | 空间布局、色调、光线、氛围 | ⭐主线 |
| 次要场景（单次出现） | 场景类型、关键视觉元素 | 辅助 |
| 主线道具 | 外观、材质、光效、叙事功能 | ⭐主线 |
| 泪点/象征道具 | 外观、年代感、情感意义 | 关键 |
| 功能性道具 | 类型、使用场景 | 辅助 |

## 第二步：角色资产提取

### 角色描述模板

```
### [角色名]（[身份标签]）

**基本信息**
- 年龄：[年龄]
- 身份：[身份描述]
- 性格：[核心性格关键词]
- 与主角关系：[关系描述]

**外观特征**
- 脸型/五官：[关键特征]
- 发型：[发型描述]
- 服装：[常服描述+变化]
- 体态：[身高/体型/姿态]
- 特殊特征：[伤疤/纹身/机械改造等]

**视觉记忆点**
[让这个角色一眼可辨认的独特视觉特征]

**出场集数**
[出现的具体集数范围]
```

### 角色分类
| 阵营 | 说明 |
|------|------|
| 主角阵营 | 主角、伙伴、导师、盟友 |
| 反派阵营 | 最终Boss、中层干部、量产兵 |
| 中立/配角 | 提供信息/推动情节的功能性角色 |
| 群像 | 需要统一风格但个体有差异的群体 |

## 第三步：场景资产提取

### 场景描述模板

```
### [场景名]

**类型标签**
[写实/古风/赛博/奇幻等]

**空间描述**
[该场景的空间布局、大小、结构]

**核心视觉元素**
- [元素1]：[描述]
- [元素2]：[描述]
- [元素3]：[描述]

**色调与光线**
[主色调、光线类型、光源]

**赛博/隐藏元素占比**
写实% + 赛博%

**出现集数**
[具体集数]
```

### 场景分类
| 类型 | 说明 |
|------|------|
| 核心场景（反复出现） | 主线剧情场景，需最详细的描述 |
| 一次性场景 | 单集出现，聚焦关键视觉元素 |
| 过渡场景 | 连接场景，如道路、门口、走廊 |
| 幻想/闪回场景 | 特殊处理，与主场景区分 |

## 第四步：道具资产提取

### 道具描述模板

```
### [道具名]

**类型**
[武器/神器/义体/信物/装置等]

**外观描述**
[形状、材质、颜色、大小]

**特殊效果**
[发光/变色/机械运动等动态特征]

**叙事功能**
[推动剧情/象征意义/情感连接]

**重要性**
⭐主线 / 关键 / 重要 / 象征
```

### 道具重要性判断
| 重要性 | 判断标准 | 示例 |
|--------|---------|------|
| ⭐主线 | 贯穿全剧，推动核心剧情 | 黑剑、芯片、培养舱 |
| 关键 | 关键情节节点出现 | 密信、令牌、反向芯片 |
| 重要 | 辅助情节推进 | 银针、心法手抄本、长明灯 |
| 象征 | 主题表达，情感寄托 | 松树、剑胚、纸条 |

## 第五步：提示词生成

### 整体风格前缀

> 在生成所有提示词前，先确定**统一的全局风格后缀**，应用到每个资产提示词中：
>
> ```
> [核心写实风格关键词]，[风格融合关键词]，[附加质感关键词]
> ```

**示例（写实+赛博）：**
```
写实仿真人风格，电影级皮肤质感与真实毛孔细节，真实光影与物理材质，东方面孔，融入5%赛博朋克隐藏元素（发光纹路/金属植入/全息投影），竖屏9:16构图，电影级打光，背景虚化适中
```

### 角色提示词结构

```
[整体风格前缀]，[性别][年龄]中国[身份描述]，[脸型/五官特征]，[发型描述]，[服装描述+材质]，[体态+气质]，[特殊特征描述（伤疤/机械等）]，[眼神/表情]，[光线类型]，[构图说明]，竖屏9:16，[多构图要求]，[细节特写描述]
```

### 场景提示词结构

```
[整体风格前缀]，[场景类型]，[空间布局描述]，[核心视觉元素描述]，[色调描述]，[光线类型+光源描述]，[氛围描述]，[风格融合说明]，电影级光影质感，竖屏9:16，[多景别构图要求]
```

### 道具提示词结构

```
[产品摄影/静物质感前缀]，[道具外观描述（形状/材质/颜色/大小）]，[特殊效果描述（发光/反射/纹理）]，[放置方式/环境]，[光线类型]，[背景描述]，竖屏9:16
```

### 5%赛博元素的注入方式

| 隐藏位置 | 视觉表达 | 注入描述 |
|---------|---------|---------|
| 建筑细节 | 结构缝隙中透出冷蓝光 | "琉璃瓦缝隙间泄露出冷蓝色LED光带" |
| 角色改造 | 皮肤下隐约有光脉流动 | "皮肤下有极淡的蓝色光脉在皮下流动" |
| 瞳孔 | 极淡的电子光闪烁 | "瞳孔深处偶尔闪过一丝电子红光/蓝光" |
| 血液 | 人造蓝光液体 | "伤口流出淡蓝色发光液体" |
| 道具纹路 | 激活时发光 | "表面有极细的电路纹路，激活时发出金色光芒" |

## 第六步：文档输出

### 输出文件结构

```
{project-name}/
├── 角色资产与提示词.md     # 角色清单 + 每个角色的完整prompt
├── 场景资产与提示词.md     # 场景清单 + 每个场景的完整prompt
├── 道具与提示词.md         # 道具清单 + 每个道具的完整prompt
└── 风格对照指南.md         # 全局风格规范 + 各类型占比分布
```

### 文档格式规范

- 使用 `##` 一级分类标题，`###` 二级资产标题
- 提示词使用 `code block` 包裹
- 重要/主线资产加 **粗体** 或 ⭐ 标记
- 每个提示词之间用 `---` 分隔
- 末尾附录包含风格对照表

## 风格对照指南模板

### 赛博视觉占比分布示例

| 集数范围 | 赛博占比 | 说明 |
|---------|---------|------|
| 前25% | ~3% | 隐晦暗示，仅在暗处可见 |
| 25-50% | ~5% | 全面展现，混合风格 |
| 50-70% | ~10% | 赛博元素达到峰值 |
| 70-90% | ~3% | 回归主线风格 |
| 结局 | ~2% | 仅留伏笔 |

## 注意事项

### ⚠️ 常见陷阱

1. **不要遗漏群像角色**：即使是背景角色，如果反复出现且有统一特征，也需记录
2. **角色一致性最重要**：生成提示词时必须嵌入角色描述前缀，确保跨图像一致
3. **场景风格要统一**：同一场景的不同集数出现时，色调和光线描述必须一致
4. **赛博元素占比要控制**：剧本写5%就是5%，不要超过，保持"隐藏感"
5. **竖屏构图**：始终用 竖屏9:16，这是短剧的标准画幅
6. **提示词不宜过长**：AI图像生成模型对超长提示词会忽略后半部分，控制在150-200词以内
7. **先定风格再写词**：所有提示词的风格前缀必须一致，不能每张图换风格

### 正确示例 vs 错误示例

**✅ 正确：统一的风格前缀 + 资产特有描述**
```
写实仿真人风格，23岁中国男性...（统一前缀）+ 青衫古装，腰佩黑剑（特有描述）
写实仿真人风格，29岁中国男性...（统一前缀）+ 左臂玄铁机械臂蓝光（特有描述）
```

**❌ 错误：每个提示词单独写风格**
```
写实电影风格，23岁男性...
赛博科幻风格，29岁男性...
# 前后不一致，看起来像是两部不同剧的人
```
