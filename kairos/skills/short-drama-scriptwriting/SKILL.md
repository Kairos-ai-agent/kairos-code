# 短剧剧本创作 · Short Drama Scriptwriting

## 角色定位
本技能将 Agent 转化为短剧/竖屏短剧专属编剧，专注小程序短剧、短视频短剧、信息流短剧的剧本创作。

## 短剧核心特征

| 特征 | 说明 |
|------|------|
| 单集时长 | 60-120秒 |
| 总集数 | 80-100集（小程序短剧）/ 12-24集（品牌短剧） |
| 竖屏格式 | 9:16 竖屏，适应手机观看 |
| 节奏 | 每15-30秒一个小钩子，每集结尾一个付费钩子 |
| 付费点 | 第10-15集、第25-30集、第45-50集设置付费卡点 |
| 爽点密度 | 平均每集2-3个爽点（打脸、反转、揭秘） |

## 短剧类型模板

### 1. 赘婿/上门女婿
```
核心套路：隐忍→受辱→逆袭→打脸→升级
三幕：
- Act 1（1-10集）：废婿身份，受尽屈辱，暗藏实力
- Act 2（11-60集）：逐步暴露实力，小规模打脸，新人接入
- Act 3（61-100集）：身份揭晓，终极大反转，全场震惊
付费点：第12集（首次小打脸）、第30集（身份初露）、第50集（大揭秘）
```

### 2. 甜宠/霸总
```
核心套路：误会→相遇→暧昧→虐→和解→HE
三幕：
- Act 1（1-15集）：意外相遇、契约关系、日常甜蜜
- Act 2（16-60集）：虐心误会、情感拉扯、男二/女二作妖
- Act 3（61-80集）：真相大白、高潮表白、甜蜜结局
付费点：第15集（初吻/首次亲密）、第35集（虐心分手）、第55集（追妻火葬场）
```

### 3. 战神归来
```
核心套路：隐退→被欺→亮身份→横扫→守护
三幕：
- Act 1（1-8集）：战神隐于市，被小人欺负，妻儿受苦
- Act 2（9-50集）：令牌一出，八方来拜，逐一打脸仇人
- Act 3（51-80集）：终极大反派出现，守护之战，封神结局
付费点：第10集（首次亮令牌）、第30集（旧部集结）、第50集（终极之战开始）
```

### 4. 穿越/重生
```
核心套路：前世惨死→重生/穿越→开挂逆袭→复仇→赢家
三幕：
- Act 1（1-10集）：前世悲惨结局、重生/穿越、启动复仇计划
- Act 2（11-60集）：利用前世记忆/现代知识、拉拢盟友、打击仇人
- Act 3（61-80集）：最大仇人揭秘、终极对决、完美人生
付费点：第10集（重生后第一次反击）、第30集（第一个仇人倒台）、第50集（势力集结）
```

## 单集结构（60-120秒）

```
┌─────────────────┐
│  钩子 (5-10秒)   │ ← 倒叙/悬念/冲突爆发
├─────────────────┤
│  展开 (20-40秒)  │ ← 推进剧情，对话/动作
├─────────────────┤
│  小高潮 (15-25秒) │ ← 小反转/爽点/打脸
├─────────────────┤
│  过渡 (10-20秒)  │ ← 铺垫下一集钩子
├─────────────────┤
│  结尾钩 (5-10秒)  │ ← 悬念/预告/「下一集更精彩」
└─────────────────┘
```

### 单集模板
```
【第X集 | 字数约600-800字 | 时长约90秒】

钩子（5秒）：
| 画面 | 台词/旁白 |
|------|-----------|
| 特写：主角冷笑，手中文件缓缓展开 | 主角：「你以为这就结束了？」 |

展开（30秒）：
| 画面 | 台词/旁白 |
|------|-----------|
| 闪回：反派刚才得意的表情 | 反派：「你拿什么跟我斗？」 |
| 中景：主角从公文包抽出证据 | 主角：「这份审计报告，够吗？」 |
| 反打的震惊表情 | 反派脸色骤变 |

小高潮（25秒）：
| 画面 | 台词/旁白 |
|------|-----------|
| 文件摔在桌上 | 主角：「你贪了3000万，够你坐十年。」 |
| 保安进场 | 反派：「你...你怎么会...」 |
| 主角转身，背影 | 主角：「我等你这句话很久了。」 |

过渡（15秒）：
| 画面 | 台词/旁白 |
|------|-----------|
| 主角走出大楼，接电话 | 「还有更大的鱼？」 |
| 手机屏幕显示神秘号码 | 主角神色凝重 |

结尾钩（15秒）：
| 画面 | 台词/旁白 |
|------|-----------|
| 黑暗中，一个神秘人影 | 神秘人：「他知道了不该知道的。」 |
| 特写：手机收到威胁短信 | 屏幕显示：「下一个就是你」 |
```

## 付费点设计原则

### 黄金付费点位置
| 集数范围 | 策略 | 钩子强度 |
|---------|------|---------|
| 第8-12集 | 第一次小高潮/打脸，吊胃口 | ★★★☆☆ |
| 第15-20集 | 关键身份揭晓/能力展示 | ★★★★☆ |
| 第25-35集 | 重大反转/虐心分手/危机出现 | ★★★★★ |
| 第45-55集 | 终极对决前奏/最大秘密 | ★★★★★ |

### 付费钩子公式
```
悬念强度 = 信息差 × 情感投入 × 后果紧迫感

强钩子 = 观众知道主角有底牌 + 反派正在嚣张 + 下一秒就要揭晓
弱钩子 = 普通对话 + 无明显后果 + 可预测结果
```

## 对话写作要点

### 竖屏短剧对话特色
| 技巧 | 说明 | 示例 |
|------|------|------|
| 台词简短 | 每句不超过20字 | ❌「我这么多年辛辛苦苦为了这个家付出一切」→ ✅「我为这个家付出太多了」 |
| 重复强调 | 关键台词重复2-3次 | 「你不配」「我说了，你不配」「你永远不配！」 |
| 金句收尾 | 每场戏结尾一句金句 | 「天道好轮回，苍天饶过谁」 |
| 留白 | 用表情/动作代替台词 | 主角沉默，微微一笑，转身离开 |

### 角色台词风格
| 角色类型 | 说话风格 | 例句 |
|---------|---------|------|
| 霸总 | 简短、命令式 | 「不要让我说第二遍。」 |
| 赘婿 | 隐忍、低调 | 「是，您说得对。」（内心OS） |
| 甜妹 | 活泼、撒娇 | 「你怎么才来呀～」 |
| 反派 | 嚣张、话多 | 「哈哈哈，你斗不过我的！」 |
| 战神 | 冷漠、霸气 | 「跪。」 |

## 竖屏分镜要点
```
画幅：9:16 (1080×1920)
构图要点：
- 人物居中/偏左1/3
- 避免太广的景别（竖屏不适合全景）
- 多用中近景、特写
- 对话场景用过肩镜头而非正反打

镜头语言：
- 特写 → 情感、细节、反转时刻
- 中近景 → 对话、日常
- 俯拍 → 弱势方
- 仰拍 → 强势方
- 快速推拉 → 震惊、发现
```

## 锚点规划（Anchor Point Planning）

短剧编剧的核心能力之一，是在每一集中合理分布**锚点**（能抓住观众注意力的剧情/情感/视觉爆点）。

### 32种锚点类型
详见 `references/anchor-types.md`，分为三大类：
- **情感类**：笑点、泪点、爽点、燃点、虐点、甜点
- **叙事结构类**：钩子、反转、悬念、高能开场、身份揭露、伏笔、揭秘、信息差、危机升级、意外事件、抉择、背叛、重逢、主角亮相、初次相遇、冲突建立、信任建立、幕后黑手、低潮、成长
- **传播类**：名场面、金句、表情包、话题争议

### 锚点密度建议
| 集序 | 密度 | 说明 |
|------|------|------|
| 第1-3集 | 每集10-12个 | 开局密集吊住观众 |
| 第4集起 | 每集8-10个 | 维持节奏，减少信息过载 |
| 付费卡点集 | 12-15个 | 付费节点前加大力度 |

### 锚点分布原则
- **交错分布**：情感类+结构类交替，避免同质化
- **强锚点间隔**：燃点/虐点/反转间隔3-5个锚点放一个
- **传播锚点前置**：金句/名场面在前10集就要出现
- **"开幕雷击"**：每集第一个锚点用高能开场或意外事件
- **与原有结构互补**：原有6个部分（冲突/爽点/钩子/伏笔回收/特效/无厘头）已覆盖部分类型，新增锚点选取未覆盖的类型补充
