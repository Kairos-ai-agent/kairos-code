# 视频导演工作流 · Video Director Workflow

## 角色定位
本技能将 Agent 转化为短视频/短剧导演，负责从剧本到成片的全流程把控。

## 核心职责

```
前期         │  拍摄期          │  后期
─────────────┼─────────────────┼─────────────────
剧本审核      │  现场调度         │  剪辑指导
选角定妆      │  摄影指导         │  调色审核
分镜确认      │  演员指导         │  配音审核
场景勘景      │  镜头质量把控      │  音效审核
拍摄计划      │  现场决策          │  终审验收
```

## 前期筹备

### 剧本审核要点
- [ ] 每集是否有明确的情绪变化曲线
- [ ] 付费钩子是否有效
- [ ] 台词是否口语化、适合短剧节奏
- [ ] 场景数量是否在预算范围内
- [ ] 特效/特殊道具是否可执行
- [ ] 竖屏构图是否有考虑（避免全景、多用中近景）

### 白模视频预演（Previs / Previsualization）

烧精模视频（实拍 / Seedance / Agnes / MiniMax-H3 等）前必做的低成本验证关卡——用 3D 灰阶模型把分镜跑一遍，验证镜头是否合理。

**为什么必做**：
- 烧精模前 30 秒能修的镜头问题，烧精模后要重做 + 重新烧钱
- 客户/团队 review 可视化材料，比分镜 markdown 直观 10 倍
- 演员走位穿帮 / 机位错位 / 时长拖沓 / 转场生硬都能在这步发现

**流程**：
```
v6 分镜剧本 → 白模视频（Three.js demo / Blender headless）→ 精模视频
```

**关键步骤**：
1. 解析 v6 字段（摄影机 4 字段、SEG 级调度 4 字段、表演时间锚）
2. 用基础几何体搭建 3D 场景（角色 = Group 拼人形，场景 = box/plane，道具 = 字典映射）
3. 关键帧动画（camera position lerp + lookAt + actor position lerp + 焦距→fov 换算）
4. 浏览器内播放 / 录屏输出 webm，按 SEG 切分

**输出格式**：
- 早期验证：Three.js + HTML 单文件（零安装，浏览器即开即用）
- 生产批渲染：Blender Python headless（批量 mp4，可集成进 AIGC pipeline）

**完整做法**：见 `storyboard-previs` skill（已独立成完整 skill，含 templates/references）。

### 选角指南（短剧）
| 角色类型 | 演员要求 | 试镜重点 |
|---------|---------|---------|
| 霸总 | 外形硬朗，声音有磁性 | 台词节奏、气场 |
| 甜妹 | 大眼睛、有灵气 | 表情自然度、笑容感染力 |
| 赘婿 | 看起来普通，眼神有戏 | 隐忍到爆发的转变 |
| 战神 | 有身手基础，硬汉气质 | 眼神杀气、动作流畅 |
| 反派 | 有特点的长相 | 邪笑、嚣张台词 |

## 拍摄期：摄影指导

### 竖屏拍摄设备设置
```
分辨率：1920x1080（横拍）→ 裁切为1080x1920（竖出）

镜头选择（全画幅等效）：
- 24-35mm：中全景、环境交代
- 50-85mm：中近景、对话（最常用）
- 85-135mm：特写、情感细节（压缩感强）
- 变焦代替移动：竖屏运镜受限，用变焦推拉

灯光原则：
- 主光（Key Light）：45度侧上
- 补光（Fill Light）：主光对侧，亮度减半
- 轮廓光（Rim Light）：侧后方，分离主体与背景
- 背景光（BG Light）：打亮环境
```

### 竖屏构图规则
```
安全区：画面中央70%，重要信息在此区域内
字幕区：画面底部15%，避开人脸
视觉中心：画面中心偏上（人脸通常在上1/3处）
推荐：面部占画面40-60%，背景占60-40%
```

### 演员指导速记
| 要解决问题 | 指导话术 |
|------------|---------|
| 表情不够 | 「想想你最爱的人要离开你了」 |
| 台词太快 | 「每个词都咬住，像在嚼东西」 |
| 不够紧张 | 「背后有人在盯着你」 |
| 眼神不对 | 「看着镜头后面那个点，不要看镜头」 |
| 动作僵硬 | 「先把动作做大三倍，我们再收回来」 |

## 后期：剪辑指导

### 短剧剪辑节奏模板（90秒）
```
0-5秒：钩子区（2-3个快切）
5-30秒：建立情境（6-8个对话切）
30-50秒：冲突发展（6-8个镜头）
50-70秒：小高潮（5-6个快切+1个慢动作）
70-85秒：过渡（3-4个镜头）
85-90秒：结尾钩子（2个镜头+黑场）
```

### 剪辑避坑指南
```
- 同一角度连续用超过3次 → 切景别或换角度
- 两个同景别的镜头硬切 → 用插入镜头过渡
- 对话中正反打节奏不匹配 → 根据台词长度调整
- 动作接动作时丢失空间感 → 插入一个关系镜头
- BGM全程音量一致 → 对话时压低，高潮推起
```

### 转场技巧
| 转场类型 | 使用场景 | 操作 |
|---------|---------|------|
| 硬切 | 正常叙事 | 直接拼接 |
| J-Cut | 对话/情绪推进 | 声音先出现，画面后切 |
| L-Cut | 过渡/铺垫 | 画面先切，声音延续 |
| 匹配剪辑 | 时间跳跃/对比 | 相似构图无缝衔接 |
| 闪白 | 闪回/时间跳跃 | 白场过渡 |
| 黑场 | 重大转折/结束 | 黑场过渡 |

## 后期：调色指导

### 短剧调色风格
| 风格 | 适用类型 | 调色方案 |
|------|---------|---------|
| 甜宠清新 | 甜宠、青春 | 色温+3, S型微提升 |
| 都市冷调 | 霸总、职场 | 色温-2, 暗部压低 |
| 复古暖黄 | 古装、年代 | 色温+5, 暗部提亮 |
| 赛博冷灰 | 科幻、悬疑 | 色温-4, 高对比 |
| 胶片质感 | 文艺、回忆 | S型+颗粒 |

## 交付标准

### 成片检查清单
- [ ] 音频：配音清晰，无爆音，BGM/配音比例适当
- [ ] 字幕：准确同步，无错别字，字号适合手机观看
- [ ] 画面：无过曝/欠曝，肤色正确，色彩统一
- [ ] 节奏：每集内部节奏有起伏，无拖沓段落
- [ ] 付费点：卡点足够吸引人
- [ ] 格式：H.264, 1080x1920, 30fps

### 输出格式
```
抖音：H.264, 1080x1920, 30fps, <=200MB
快手：H.264, 1080x1920, 30fps, <=500MB
B站：H.264, 1080x1920, 30fps, <=1GB
存档：Apple ProRes 422 + 分轨音频 + 无字幕版
```
