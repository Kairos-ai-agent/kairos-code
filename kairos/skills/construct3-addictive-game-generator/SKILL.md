# Construct3高成瘾性游戏生成插件

专为Claw智能体打造的全自动Construct3高质量成瘾游戏生成引擎，让智能体自主完成从游戏策划、Construct3制作、调试优化到成品导出的完整工作流。

## 核心功能模块

### 一、高成瘾性游戏智能策划

#### 游戏品类精准定位
| 品类 | 特点 | 变现潜力 |
|------|------|---------|
| 解压闯关类 | 压力释放+即时满足 | 极高 |
| 合成养成类 | 收集欲望+数值成长 | 高 |
| 敏捷挑战类 | 竞争激励+排行榜 | 高 |
| 趣味竞技类 | 社交互动+对战 | 中高 |
| 放置收集类 | 碎片时间+长期留存 | 中 |

#### 成瘾性核心机制植入
- **即时正向反馈**：每次操作都有视觉/音效/数值反馈
- **阶梯式渐进难度**：玩家能力成长匹配关卡难度提升
- **稀缺随机奖励**：稀有道具/角色概率掉落
- **成就激励体系**：多维度成就目标，持续激励
- **复玩触发钩子**：每日任务/签到/限时活动
- **目标递进闭环**：短期目标→中期目标→长期目标

#### 自动生成策划方案
- 游戏玩法规则文档
- 关卡体系设计
- 奖励机制配置
- 交互逻辑流程
- 美术风格定位

### 二、Construct3全流程自动化制作

#### 项目自动创建
- 画布尺寸适配（竖屏优先，适配移动端）
- 帧率优化配置（60FPS稳定）
- 包体大小控制（<5MB目标）

#### 场景自动搭建
- 主菜单场景
- 游戏核心场景
- 结果/结算场景
- 设置/商店场景

#### UI自动化布局
- 按钮组（开始/暂停/返回）
- HUD显示（分数/时间/生命）
- 弹窗系统（奖励/成就/失败）
- 设置面板

#### 事件逻辑自动编写
- 玩家输入处理
- 游戏状态管理
- 碰撞检测配置
- AI行为逻辑
- 成就系统触发

### 三、质量标准把控

#### 美术质感标准
- 界面排版：黄金比例/栅格系统
- 色彩搭配：主色+辅色+强调色
- 元素质感：扁平化/微质感/毛玻璃
- 动画流畅：60FPS+过渡动画

#### 游戏体验标准
- 操作极简：单指操作优先
- 上手零门槛：新手指引3步内
- 节奏紧凑：每局3-5分钟
- 无冗余操作：核心循环简洁

#### 性能优化标准
- 包体大小：<5MB
- 运行帧率：稳定60FPS
- 内存占用：<150MB
- 加载时间：<3秒

### 四、成品自动导出

#### 导出格式
- HTML5（主流平台兼容）
- Android APK（可选）
- iOS（可选）

#### 附带产出
- 游戏使用说明
- 发布注意事项
- 广告变现接入指南

## 执行流程

### 主流程：游戏生成全流程

```
需求输入 → 游戏品类定位 → 成瘾机制设计 → 策划方案生成 → Construct3项目创建 → 场景搭建 → 逻辑编写 → 调试优化 → 质量检验 → 成品导出
```

### 详细流程

#### 阶段1：游戏策划
1. 分析用户需求
2. 确定游戏品类
3. 设计成瘾机制
4. 生成完整策划案

#### 阶段2：项目创建
1. 创建Construct3项目
2. 配置基础参数
3. 设置画布尺寸
4. 配置物理引擎

#### 阶段3：可视化搭建
1. 导入/生成素材
2. 搭建游戏场景
3. 布局UI元素
4. 配置动画效果

#### 阶段4：逻辑编写
1. 编写事件表
2. 配置触发器
3. 设置碰撞检测
4. 调试游戏流程

#### 阶段5：优化导出
1. 性能优化
2. 质量检验
3. 打包导出
4. 生成说明文档
